Domande Frequenti

Come importo gli ordini da lavorare?

Import Dati
  1. Vai alla sezione "Pianificazione" nel menu principale
  2. Clicca su "Importa Ordini" nel pannello "Ordini da Lavorare"
  3. Seleziona la data del giorno di ritiro
  4. Carica il file CSV con le colonne: Cliente, Ceramica, Peso, Tipo (urgente/prenotato/standard)
  5. Verifica il riepilogo e conferma l'importazione

Nota: Il sistema controlla automaticamente che i clienti e le ceramiche esistano nelle anagrafiche.

Come funziona l'algoritmo OR-Tools?

Algoritmo

OR-Tools utilizza un algoritmo di Vehicle Routing Problem (VRP) con Guided Local Search per trovare la soluzione ottimale. Il processo include:

Fase 1: Costruzione Iniziale

L'algoritmo crea una prima soluzione usando la strategia "Path Cheapest Arc"

Fase 2: Ricerca Locale

Migliora la soluzione scambiando e riordinando le fermate

Fase 3: Vincoli

Rispetta capacità, finestre temporali, zone e priorità

Fase 4: Ottimizzazione

Minimizza costi totali (km, tempi, penalità)

Cosa fare se ci sono ordini non assegnati?

Troubleshooting

Gli ordini possono rimanere non assegnati per diversi motivi. Ecco come risolvere:

Problema: Capacità Insufficiente

Soluzione: Aggiungi più veicoli nella fascia oraria o aumenta la tolleranza di sovraccarico nelle impostazioni.

Problema: Indirizzo Mancante o Errato

Soluzione: Verifica che cliente/ceramica abbiano coordinate GPS valide nelle anagrafiche.

Problema: Zona Incompatibile

Soluzione: Verifica le regole di compatibilità zone o aggiungi veicoli dedicati per quella zona.

Problema: Finestra Temporale Stretta

Soluzione: Amplia le finestre orarie nelle impostazioni OR-Tools o dividi gli ordini in più fasce.

Quali formati CSV sono supportati per l'import?

Formati

Il sistema supporta file CSV con queste colonne (ordine non importante):

Colonna Tipo Esempio Obbligatorio
Cliente Testo Rossi Mario Sì
Ceramica Testo Marazzi SpA Sì
Peso Numero 1500 Sì
Tipo Testo urgente / prenotato / standard No
Fascia Testo mattino / pomeriggio No

Attenzione: Il separatore deve essere virgola (,) o punto e virgola (;). Encoding UTF-8.

Glossario Tecnico

VRP (Vehicle Routing Problem)

Problema di ottimizzazione che cerca di trovare il percorso ottimale per un flotta di veicoli per servire un insieme di clienti.

Guided Local Search

Meta-euristica che guida la ricerca locale penalizzando temporaneamente le soluzioni già esplorate.

Time Window

Finestra temporale entro cui un servizio deve essere completato (es. 8:00-12:00).

Capacity Constraint

Vincolo di capacità massima (peso/volume) che un veicolo può trasportare.

Penalità (Penalty)

Costo aggiuntivo applicato quando un vincolo soft viene violato (es. ritardo consegna).

Solver Timeout

Tempo massimo (in secondi) che l'algoritmo ha per trovare la soluzione ottimale.
