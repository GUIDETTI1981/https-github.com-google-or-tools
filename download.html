Installazione Rapida

Windows

  1. 1. Estrai l'archivio
  2. 2. Entra nella cartella webapp
  3. 3. Doppio click su start_services.bat
  4. 4. Apri http://localhost:8000

Linux / macOS

  1. 1. Estrai: tar -xzf *.tar.gz
  2. 2. Entra: cd webapp
  3. 3. Esegui: ./start_services.sh
  4. 4. Apri http://localhost:8000

Prerequisiti

  • Python 3.8 o superiore
  • pip (gestore pacchetti Python)
  • Connessione internet (solo prima installazione)
