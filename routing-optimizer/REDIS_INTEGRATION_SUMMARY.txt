🏗️ ARCHITECTURE
================================================================================

Cache-Aside Pattern (Lazy Loading):

┌─────────────────────────────────────────────────────────────────┐
│  INPUT: OrderWithAddress(address="V. Garibaldi 23, Milano")   │
└────────────────────────┬────────────────────────────────────────┘
                         │
                         ▼
          ┌──────────────────────────────┐
          │  Step 1: AddressSanitizer    │
          │  "V. Garibaldi 23"           │
          │  → "Via Garibaldi 23, Milano"│
          └──────────────┬───────────────┘
                         │
                         ▼
          ┌──────────────────────────────────────────┐
          │  Step 2: GeocodeCache.get_or_fetch()    │
          │                                          │
          │  Key = MD5("via garibaldi 23, milano")   │
          │      → "geocode:a3f5e8d2..."            │
          │                                          │
          │  ┌────────────────┐                     │
          │  │ Redis GET key  │                     │
          │  └───────┬────────┘                     │
          │          │                               │
          │   ┌──────┴──────┐                       │
          │   │             │                       │
          │   ▼ HIT         ▼ MISS                  │
          │ ┌────┐      ┌──────────────┐           │
          │ │JSON│      │ Call Photon  │           │
          │ │→ OK│      │ /api?q=...   │           │
          │ └────┘      └──────┬───────┘           │
          │                    │                    │
          │                    ▼                    │
          │           ┌────────────────┐            │
          │           │ Redis SET key  │            │
          │           │ EXPIRE 2592000 │ (30 days)  │
          │           └────────┬───────┘            │
          │                    │                    │
          │                    ▼                    │
          │              Return result              │
          └─────────────────────────────────────────┘
                         │
                         ▼
      ┌───────────────────────────────────────────┐
      │  OUTPUT: Order(                           │
      │    lat=45.464664,                         │
      │    lon=9.188540,                          │
      │    demand=10                              │
      │  )                                        │
      └───────────────────────────────────────────┘

================================================================================
✨ KEY FEATURES
================================================================================

1. Pattern Cache-Aside (Lazy Loading)
   - Check cache first
   - On MISS → fetch from source → cache result
   - On HIT → return cached (instant)

2. MD5 Key Hashing
   - Character-safe Redis keys
   - Fixed length (32 characters)
   - Uniform distribution
   - Example: "geocode:a3f5e8d2c1b4f7e9..."

3. JSON Serialization
   - Structured storage
   - {latitude, longitude, confidence, address, city, country, ...}

4. Long TTL (30 days)
   - Addresses don't change frequently
   - Reduces Photon load
   - Configurable via REDIS_CACHE_TTL

5. Fail-Open Strategy
   - Redis down → bypass cache
   - No system crash
   - Graceful degradation

6. Statistics Tracking
   - Hits, misses, sets, errors
   - Hit rate calculation
   - Performance monitoring

7. Health Monitoring
   - GET /api/redis/status
   - Connection check
   - Statistics reporting

8. Persistent Storage
   - AOF (Append-Only File)
   - Volume: ./redis-data
   - Survives container restart

🔧 CONFIGURATION
================================================================================

Environment Variables (docker-compose.yml):

  backend:
    environment:
      - USE_REDIS_CACHE=true           # Enable/disable cache
      - REDIS_HOST=redis               # Redis hostname
      - REDIS_PORT=6379                # Redis port
      - REDIS_CACHE_TTL=2592000        # TTL in seconds (30 days)

Redis Service:

  redis:
    image: redis:alpine
    ports:
      - "6379:6379"
    volumes:
      - ./redis-data:/data             # Persistent storage
    command: redis-server --appendonly yes --appendfsync everysec
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]

TTL Options:
- 30 days (default): 2592000
- 60 days: 5184000
- 90 days: 7776000
- 1 year: 31536000

🔍 TROUBLESHOOTING
================================================================================

Problem: Cache always MISS

Solution:
1. Check Redis is running:
   $ docker-compose ps redis

2. Check Redis connection:
   $ docker exec routing-optimizer-redis redis-cli ping
   # PONG

3. Check environment variables:
   $ docker-compose exec backend env | grep REDIS
   # USE_REDIS_CACHE=true ✅

4. Check backend logs:
   $ docker-compose logs backend | grep -i "cache"
   # GeocodeCache initialized ✅

Problem: Redis connection error

Solution:
1. Check Redis logs:
   $ docker-compose logs redis | tail -30

2. Restart Redis:
   $ docker-compose restart redis

3. Restart Backend:
   $ docker-compose restart backend

Problem: Cache not persisting after restart

Solution:
1. Check volume exists:
   $ docker volume ls | grep redis
   # routing-optimizer_redis-data ✅

2. Check AOF persistence:
   $ docker exec routing-optimizer-redis redis-cli CONFIG GET appendonly
   # "yes" ✅

3. Check data directory:
   $ docker exec routing-optimizer-redis ls -lh /data
   # appendonly.aof ✅
